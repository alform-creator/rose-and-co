# Rose & Co — GitHub Pages edition

Static trilingual floral showcase (hy / ru / en), generated floral design concepts, 30 examples and 51 flower varieties, 4 journal posts per language. No prices, no cart, no admin panel, no online checkout. Contact via phone +374 95 806 009, WhatsApp (verify this number uses WhatsApp), Instagram @rose___co. Address: Zovuni 1st Street 117, Armenia.

This website was adapted for **https://alform-creator.github.io/rose-and-co/** and all internal links point to `/rose-and-co/`. Do not rename the GitHub repository without also changing this prefix.

## Installation
Create a **public** GitHub repository named `rose-and-co`, upload the `rose-co-site.zip` file to its root, then add the `.github/workflows/deploy.yml` workflow supplied with the setup. In Settings → Pages, select **GitHub Actions** as source and run the deployment workflow.

Photos are **illustrative concepts**, not proof of stock; confirm availability and exact arrangements by contacting the florist.
